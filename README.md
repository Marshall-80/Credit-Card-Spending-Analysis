# Credit Card Customer & Spending Analysis

## Project Overview

This project focuses on analysing credit card transaction data to understand customer spending behaviour, transaction patterns, card performance, and expense category trends using Microsoft Power BI.

The objective is to transform raw transaction data into meaningful business insights that can support data-driven decision-making in the banking and financial services industry.

## Business Objectives

- Analyse overall credit card spending and transaction activity.
- Identify the most popular expense categories.
- Compare spending patterns across different card types.
- Understand city-wise spending distribution.
- Analyse gender-wise spending behaviour.
- Identify monthly and weekday/weekend spending trends.
- Evaluate average transaction value and transaction frequency.

## Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization
- Business Intelligence

## Dataset Description

The dataset contains credit card transaction information with the following fields:

| Column | Description |
|---|---|
| City | Transaction city |
| Date | Transaction date |
| Card Type | Type of credit card |
| Exp Type | Expense category |
| Gender | Customer gender |
| Amount | Transaction amount |

## Dashboard Pages

The Power BI report contains five analytical pages covering different aspects of credit card spending.

1. Executive Spending Overview
2. Spending Trend Analysis
3. Customer Spending Analysis
4. Card Type & Expense Category Analysis
5. Additional Spending Performance Analysis

## Key Business Insights

The analysis explores:

- Expense categories contributing the highest spending.
- Differences between transaction frequency and transaction value.
- Card types generating higher spending.
- Monthly spending patterns and fluctuations.
- City-wise spending distribution.
- Differences in spending behaviour across customer segments.



## Key DAX Measures

The project uses DAX measures to calculate:

- Total Spending
- Total Transactions
- Average Transaction Value
- Spending Contribution Percentage
- Month-over-Month Spending Growth
